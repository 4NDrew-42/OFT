                          ARCHITECTURE
================================================================================

Request Flow:
  User Query
    ↓
  /api/chat/enhanced-stream
    ↓
  Generate JWT for ORION-CORE
    ↓
  Search ORION-CORE Vector Database
    ↓
  Build Enhanced Prompt with Context
    ↓
  Stream Response from AI Provider (DeepSeek/Gemini)
    ↓
  Real-time SSE to Frontend

Service Integration:
  Vercel Frontend
    ↓
  Cloudflare Tunnel
    ↓
  ORION-CORE Backend (Local)
    ├── Vector Search (8081)
    ├── Fabric Bridge (8089)
    └── Gate API (8085)
    ↓
  AI Providers (DeepSeek/Gemini)

================================================================================
                          TROUBLESHOOTING
================================================================================

Input text not visible?
  → Clear browser cache and hard refresh (Ctrl+Shift+R)

Chat not responding?
  → Check Cloudflare tunnel is running
  → Verify ORION-CORE services are healthy
  → Check browser console for errors
  → Verify JWT secret is configured

Provider dropdown not showing?
  → Verify API keys are set in environment
  → Check JavaScript is enabled
  → Hard refresh browser

Streaming interrupted?
  → Check network connection
  → Verify SSE support in browser
  → Check for proxy/firewall issues
